# GameFramework

## How to Clone & Use

Clone this repository side-by-side with your game project:

```text
ParentFolder/
 ├── GameFramework/
 └── YourGameProject/
```

git clone [https://github.com/laukachuen/GameFramework.git](https://github.com/laukachuen/GameFramework.git)

## How to Run Sandbox

1. Open GameFramework.sln in Visual Studio 2022.
2. In the Solution Explorer, right-click on the Sandbox project.
3. Select Set as Startup Project.
4. Press F5 to build and run.
